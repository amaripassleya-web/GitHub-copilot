# Mindustry Copilot
This Mindustry mod adds a simple in-game Copilot-style assistant for basic strategy and setup help.

## What it does
- Opens a small assistant window when the client loads
- Lets you ask simple Mindustry questions about:
  - starting a base
  - power generation
  - defenses
  - automation
  - late-game planning

## How to use it
1. Install the mod in a Mindustry mods folder.
2. Launch the game and wait for the assistant window to appear.
3. Type a short question such as "How do I start?" or "How do I defend my base?"

## Notes
This first version uses a built-in rule set so it works offline. It can be expanded later to use an external AI service if you want a more advanced experience.
